# Student Database CRUD API

A Python backend for managing student records (Create, Read, Update, Delete), built with **FastAPI** and **SQLite**. Includes input validation, duplicate-email protection, filtering and missing-record handling.

> Uses dummy data only. No real student information is stored in this repository.

## Features

- Create, list, view, update and delete students
- Filter students by name, course or email
- Pagination (`skip`, `limit`)
- Validation: required fields, valid email, DOB not in the future, unique email
- Clear error responses (404 not found, 409 duplicate email, 422 invalid input)
- Persistent storage in SQLite (`students.db`, created automatically)

## Prerequisites

- Python 3.10 or newer
- pip

## Installation

```bash
git clone https://github.com/<Shubhh-h>/student-crud-app.git
cd student-crud-app

python -m venv venv

# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

pip install -r requirements.txt
```

## Run

```bash
uvicorn app.main:app --reload
```

- API: http://127.0.0.1:8000
- Interactive docs (Swagger UI): http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

The SQLite file `students.db` is created automatically on first start.

## Student fields

| Field | Required | Notes |
|---|---|---|
| `id` | auto | Unique student ID, generated by the database |
| `name` | yes | 1-100 characters, whitespace trimmed |
| `date_of_birth` | yes | `YYYY-MM-DD`, cannot be in the future |
| `email` | yes | Valid email, must be unique |
| `phone` | no | Up to 20 characters |
| `course` | no | |
| `address` | no | |
| `enrollment_date` | no | `YYYY-MM-DD` |

## API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/students` | Create a student (201) |
| GET | `/students` | List / filter students |
| GET | `/students/{student_id}` | View one student |
| PUT / PATCH | `/students/{student_id}` | Update details (send only the fields to change) |
| DELETE | `/students/{student_id}` | Delete a student |

### List and filter

`GET /students` accepts these optional query parameters:

| Parameter | Description |
|---|---|
| `name` | Case-insensitive partial match |
| `course` | Case-insensitive partial match |
| `email` | Exact match |
| `skip` | Records to skip (default 0) |
| `limit` | Max records to return (default 100, max 500) |

Example: `GET /students?course=math&name=bob`

### Error responses

| Code | Meaning |
|---|---|
| 404 | Student not found |
| 409 | Email already registered |
| 422 | Invalid input (bad email, empty name, future DOB, null required field, etc.) |

## Testing the API

Use Swagger UI at `/docs`, Postman, or curl.

Example request body for `POST /students`:

```json
{
  "name": "Alice Smith",
  "date_of_birth": "2001-05-20",
  "email": "alice.smith@example.com",
  "phone": "9876543210",
  "course": "Computer Science",
  "address": "Dummy Street, Test City",
  "enrollment_date": "2023-09-01"
}
```

curl examples (Linux/macOS/Git Bash):

```bash
# Create
curl -X POST http://127.0.0.1:8000/students \
  -H "Content-Type: application/json" \
  -d '{"name":"Alice Smith","date_of_birth":"2001-05-20","email":"alice.smith@example.com","course":"Computer Science"}'

# List all / filter
curl http://127.0.0.1:8000/students
curl "http://127.0.0.1:8000/students?course=computer"

# Get one
curl http://127.0.0.1:8000/students/1

# Update
curl -X PATCH http://127.0.0.1:8000/students/1 \
  -H "Content-Type: application/json" \
  -d '{"name":"Alice Johnson"}'

# Delete
curl -X DELETE http://127.0.0.1:8000/students/1
```
